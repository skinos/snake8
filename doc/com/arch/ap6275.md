## arch@ap6275 — AP6275 SDIO Wi‑Fi driver glue

Same **architecture** as **`arch@ap6398`**: SDIO lifecycle hooks, **`setup` / `shut`**, **`config_get` / `config_set`** with **`shut`→merge→`setup`** on the underlying **`wifi@…`** radio object, and radio helper methods (`chlist`, `modelist`, `hostapd`, …). Stock **`prj.json`** maps **`sdiodrv@ap6275` → `ap6275`** module. Implementation: [`ap6275/ap6275.c`](ap6275/ap6275.c), defaults [`ap6275.cfg`](ap6275.cfg).

For **SSID / client** semantics and **`wifi@*`** JSON, use **`project/wifi/`** component docs.

### Configuration ( `arch@ap6275` )
```json
// Attributes introduction
{
    "mode":"radio PHY mode",                   // [ "n", "a", "an", "ac", ... ]
    "country":"regulatory domain",             // [ string ], e.g. "cn", "us"
    "txpower":"optional transmit power dBm",   // [ string ], e.g. "20"
    "option": { },                             // hostapd option overrides per mode
    "value": { }                               // hostapd capability values
}
```

Examples, show all the configure
```shell
arch@ap6275
{
    "mode":"n",                                # radio PHY mode is 11N
    "country":"cn",                            # regulatory domain: China
    "option":                                  # hostapd option overrides
    {
        "n":
        {
            "supported_rates":"60 90 120 180 240 360 480 540",
            "basic_rates":"60 120 240",
            "ht_coex":"0"
        },
        "ht_capab":"[DSSS_CCK-40]",
        "vht_capab":"[SU-BEAMFORMER][SU-BEAMFORMEE][MAX-MPDU-11454][MAX-A-MPDU-LEN-EXP7][VHT-LINK-ADAPT-3]"
    },
    "value":                                   # hostapd capability values
    {
        "ht_capab":
        {
            "ldpc":"",
            "stbc":""
        }
    }
}
```

Examples, merge
```shell
arch@ap6275|{"mode":"n","country":"us"}
ttrue
```

### Component API
Same family as **`arch@ap6398`**: **`chlist`**, **`modelist`**, **`securelist`**, **`acs`**, **`stalist`**, **`hostapd`**, SDIO match helpers — see [`ap6275/ap6275.c`](ap6275/ap6275.c) for any parameter differences.

### Lifecycle API
+ `setup[]` / `shut[]` — SDIO / **`arch@sdio`** match path; **not** in the **`init`** table of sample **`odm/rk3568/prj.json`**.
