## arch@ap6398 — AP6398 SDIO Wi‑Fi driver glue

SDIO **match / shutdown / disappear** hooks, **`setup` / `shut`** for bringing up **`wifi@nssid*`** / **`wifi@…sta`** virtual interfaces on the **`rootdev`** netdev, and **radio helper** APIs (`chlist`, `modelist`, `hostapd`, …). Maps from **`sdiodrv@ap6398`** in **`prj.json` → `obj`**. Sources: [`ap6398/ap6398.c`](ap6398/ap6398.c), radio options [`ap6398.cfg`](ap6398.cfg).

**End-user SSID / security configuration** is still on **`wifi@nssid`**, **`wifi@assid`**, etc. (see **`project/wifi/`** docs). **`arch@ap6398`** configures **chip/radio** layers and **registration** with **`network@frame`**.

### Configuration ( `arch@ap6398` )
Radio-level JSON (abbreviated; full tree is product + **`ap6398.cfg`** merge):

```json
// Attributes introduction
{
    "mode":"radio PHY mode",                   // [ "n", "a", "an", "ac", ... ]
    "country":"regulatory domain key",         // [ string ], e.g. "cn", "us"
    "txpower":"transmit power dBm",            // [ string ], e.g. "20"
    "option": { },                             // hostapd option overrides per mode
    "value": { }                               // hostapd capability values
}
```

Per-SSID JSON lives under **`wifi@nssid`**, **`wifi@nssid2`**, … and is loaded by **`setup[]`**.

Examples, show all the configure
```shell
arch@ap6398
{
    "mode":"ac",                               # radio PHY mode is 11AC
    "country":"cn",                            # regulatory domain: China
    "option":                                  # hostapd option overrides
    {
        "n":
        {
            "supported_rates":"60 90 120 180 240 360 480 540",
            "basic_rates":"60 120 240",
            "ht_coex":"0"
        },
        "a":
        {
            "tx_queue_data2_burst":"2.0",
            "ht_coex":"0"
        },
        "ht_capab":"[DSSS_CCK-40]",
        "vht_capab":"[MU-BEAMFORMEE][MAX-A-MPDU-LEN-EXP0]"
    },
    "value":                                   # hostapd capability values
    {
        "ht_capab":
        {
            "ldpc":"",
            "stbc":""
        }
    }
}
```

Examples, merge mode/country
```shell
arch@ap6398|{"mode":"ac","country":"cn"}
ttrue
```

### Component API
+ `chlist[ [mode], [country] ]` **allowed channel map JSON** (defaults from saved **`mode`** / **`country`**).

+ `modelist[]` **fixed JSON of supported PHY width modes**.

+ `securelist[]` / `acs[]` / `stalist[]` **driver capability / ACS / station list helpers**.

+ `hostapd[]` **regenerate or signal hostapd** (see [`ap6398/ap6398.c`](ap6398/ap6398.c)).

+ SDIO bus hooks **`sdio_match`**, **`sdio_shutdown`**, **`sdio_disappear`** — invoked by the SDIO stack when the module appears or is removed (not typical operator HE commands).

**`_set` behavior:** **`shut`** on the target **`wifi@…`** radio object, **`config_set`**, then **`setup`** — see [`ap6398/ap6398.c`](ap6398/ap6398.c).

### Lifecycle API
+ `setup[]` / `shut[]` **create/destroy virtual AP/STA netdevs and `network@frame` registrations**.
    - **Not** listed in stock **`odm/rk3568/prj.json`** `init`; normally triggered after **`arch@sdio`** matches the module.
