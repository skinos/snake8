## arch@ap6398 — AP6398 SDIO Wi-Fi 驱动适配层

SDIO **匹配 / 关闭 / 消失** 钩子、用于在 **`rootdev`** 网络设备上启动 **`wifi@nssid*`** / **`wifi@...sta`** 虚拟接口的 **`setup` / `shut`**，以及 **射频辅助** 接口（`chlist`、`modelist`、`hostapd` 等）。在 **`prj.json` → `obj`** 中由 **`sdiodrv@ap6398`** 进行映射。源码：[`ap6398/ap6398.c`](ap6398/ap6398.c)，射频选项 [`ap6398.cfg`](ap6398.cfg)。

**终端用户 SSID / 安全配置** 仍在 **`wifi@nssid`**、**`wifi@assid`** 等组件上（参阅 **`project/wifi/`** 文档）。**`arch@ap6398`** 负责配置 **芯片/射频** 层以及向 **`network@frame`** 进行 **注册**。

### 配置项 ( `arch@ap6398` )
射频级别 JSON（简要列出；完整配置树由产品配置与 **`ap6398.cfg`** 合并生成）：

```json
// Attributes introduction
{
    "mode":"radio PHY mode",                   // [ "n", "a", "an", "ac", ... ]
    "country":"regulatory domain key",         // [ string ], e.g. "cn", "us"
    "txpower":"transmit power dBm",            // [ string ], e.g. "20"
    "option": { },                             // hostapd option overrides per mode
    "value": { }                               // hostapd capability values
}
```

每个 SSID 的 JSON 配置位于 **`wifi@nssid`**、**`wifi@nssid2`** 等组件下，由 **`setup[]`** 加载。

示例，显示所有配置
```shell
arch@ap6398
{
    "mode":"ac",                               # 射频 PHY 模式为 11AC
    "country":"cn",                            # 监管域：中国
    "option":                                  # hostapd 选项覆盖
    {
        "n":
        {
            "supported_rates":"60 90 120 180 240 360 480 540",
            "basic_rates":"60 120 240",
            "ht_coex":"0"
        },
        "a":
        {
            "tx_queue_data2_burst":"2.0",
            "ht_coex":"0"
        },
        "ht_capab":"[DSSS_CCK-40]",
        "vht_capab":"[MU-BEAMFORMEE][MAX-A-MPDU-LEN-EXP0]"
    },
    "value":                                   # hostapd 能力值
    {
        "ht_capab":
        {
            "ldpc":"",
            "stbc":""
        }
    }
}
```

示例，合并模式/国家
```shell
arch@ap6398|{"mode":"ac","country":"cn"}
ttrue
```

### 组件接口
+ `chlist[ [mode], [country] ]` **允许的频道映射 JSON**（默认值来自已保存的 **`mode`** / **`country`**）。

+ `modelist[]` **支持的 PHY 带宽模式的固定 JSON**。

+ `securelist[]` / `acs[]` / `stalist[]` **驱动能力 / ACS / 站点列表辅助函数**。

+ `hostapd[]` **重新生成或发送信号给 hostapd**（参阅 [`ap6398/ap6398.c`](ap6398/ap6398.c)）。

+ SDIO 总线钩子 **`sdio_match`**、**`sdio_shutdown`**、**`sdio_disappear`** — 在模块出现或被移除时由 SDIO 协议栈调用（非典型的 HE 操作命令）。

**`_set` 行为：** 对目标 **`wifi@...`** 射频对象执行 **`shut`**，然后 **`config_set`**，再执行 **`setup`** — 参阅 [`ap6398/ap6398.c`](ap6398/ap6398.c)。

### 生命周期接口
+ `setup[]` / `shut[]` **创建/销毁虚拟 AP/STA 网络设备以及 `network@frame` 注册**。
    - 在默认的 **`odm/rk3568/prj.json`** `init` 中 **未** 列出；通常在 **`arch@sdio`** 匹配到模块后触发。
