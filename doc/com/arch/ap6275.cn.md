## arch@ap6275 — AP6275 SDIO Wi-Fi 驱动适配层

与 **`arch@ap6398`** 采用相同的 **架构**：SDIO 生命周期钩子、**`setup` / `shut`**、**`config_get` / `config_set`**（对底层 **`wifi@...`** 射频对象执行 **`shut`→合并→`setup`** 流程）以及射频辅助方法（`chlist`、`modelist`、`hostapd` 等）。默认 **`prj.json`** 中将 **`sdiodrv@ap6275` → `ap6275`** 模块进行映射。实现文件：[`ap6275/ap6275.c`](ap6275/ap6275.c)，默认配置 [`ap6275.cfg`](ap6275.cfg)。

有关 **SSID / 客户端** 语义和 **`wifi@*`** JSON 配置，请参阅 **`project/wifi/`** 组件文档。

### 配置项 ( `arch@ap6275` )
```json
// Attributes introduction
{
    "mode":"radio PHY mode",                   // [ "n", "a", "an", "ac", ... ]
    "country":"regulatory domain",             // [ string ], e.g. "cn", "us"
    "txpower":"optional transmit power dBm",   // [ string ], e.g. "20"
    "option": { },                             // hostapd option overrides per mode
    "value": { }                               // hostapd capability values
}
```

示例，显示所有配置
```shell
arch@ap6275
{
    "mode":"n",                                # 射频 PHY 模式为 11N
    "country":"cn",                            # 监管域：中国
    "option":                                  # hostapd 选项覆盖
    {
        "n":
        {
            "supported_rates":"60 90 120 180 240 360 480 540",
            "basic_rates":"60 120 240",
            "ht_coex":"0"
        },
        "ht_capab":"[DSSS_CCK-40]",
        "vht_capab":"[SU-BEAMFORMER][SU-BEAMFORMEE][MAX-MPDU-11454][MAX-A-MPDU-LEN-EXP7][VHT-LINK-ADAPT-3]"
    },
    "value":                                   # hostapd 能力值
    {
        "ht_capab":
        {
            "ldpc":"",
            "stbc":""
        }
    }
}
```

示例，合并配置
```shell
arch@ap6275|{"mode":"n","country":"us"}
ttrue
```

### 组件接口
与 **`arch@ap6398`** 同一系列：**`chlist`**、**`modelist`**、**`securelist`**、**`acs`**、**`stalist`**、**`hostapd`**、SDIO 匹配辅助函数 — 参数差异详见 [`ap6275/ap6275.c`](ap6275/ap6275.c)。

### 生命周期接口
+ `setup[]` / `shut[]` — SDIO / **`arch@sdio`** 匹配路径；在示例 **`odm/rk3568/prj.json`** 的 **`init`** 表中 **未** 列出。
